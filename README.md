## Selected Work

### [Prism](https://github.com/samarthsaxena2004/prism) &nbsp;·&nbsp; [live](http://prism.samarthsaxena.dev) &nbsp;·&nbsp; [demo](https://www.youtube.com/watch?v=LOOsFYnBOYc)
Handwritten paper forms digitized by a five-agent AI swarm in **12 seconds**. Documents route through a dynamic pipeline — vision extraction, parallel web research and API enrichment, then artifact generation — adapting to insurance, government, financial, logistics, and operations templates.
- **Stack:** Cerebras Inference (`gemma-4-31b`), Python, FastAPI, Asyncio, SSE streaming, Next.js 14, Supabase
- **The interesting part:** at typical GPU speeds (~47s) a 5-agent pipeline is a background batch job. At Cerebras speeds (~1,500 TPS) it becomes real-time UX — you photograph a form and hand back validated records before the client leaves the room.
- Built for the Cerebras × Google DeepMind Gemma 4 Hackathon across the Enterprise Impact, Multiverse Agents, and People's Choice tracks.

### [FlickAI](https://github.com/samarthsaxena2004/flickAI) &nbsp;·&nbsp; 🏆 1st Place
A context-aware desktop assistant that sees what you see — screen understanding via OCR and vision models, answering against whatever is actually in front of you.
- **Stack:** TypeScript, Cerebras GLM 4.7, Cline, OCR/vision pipeline
- **Won 1st place** in the Cerebras × Cline GLM 4.7 Hackathon — $2,500 USD and Cerebras Code plans. Built in 24 hours.

### [ResQ Orchestrator](https://github.com/samarthsaxena2004/resq-orchestrator) &nbsp;·&nbsp; [live](https://resq-orchestrator.samarthsaxena.dev)
A self-healing distributed job queue. Failed jobs aren't just retried — an LLM agent diagnoses the failure and decides the recovery path, with a real-time dashboard over the whole system.
- **Stack:** Go, Redis, Gemini, real-time dashboard
- **Focus:** fault tolerance, distributed systems, backend orchestration

### [NoteWave](https://github.com/samarthsaxena2004/note-wave) &nbsp;·&nbsp; [live](https://notewave.samarthsaxena.dev)
Turns any PDF into something you'd actually want to study from: RAG-powered research chats, 3D flashcards, and audio-synced AI host conversations that talk through the material with you.
- **Stack:** TypeScript, Pinecone, HuggingFace, Deepgram, ElevenLabs, RAG

### [AI Knowledge Hub](https://github.com/samarthsaxena2004/ai-knowledge-hub) &nbsp;·&nbsp; [live](https://second-brain.samarthsaxena.dev)
A containerized personal knowledge backend — document ingestion, vector search, and retrieval built for resource efficiency and painless deployment.
- **Stack:** FastAPI, Docker, LangChain, ChromaDB, Next.js, RAG

### [PlayDungeon](https://github.com/samarthsaxena2004/PlayDungeon) &nbsp;·&nbsp; [live](http://play-dungeon.samarthsaxena.dev)
An AI-native roguelike where the Dungeon Master is an agent and the interface generates itself. Voice-driven gameplay, generative UI, interactive narrative that isn't on rails.
- **Stack:** TypeScript, Tambo Agentic Intelligence, Next.js, React, voice input
